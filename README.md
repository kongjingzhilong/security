# 网络安全不可不知的事
> 免责声明：本文档仅为个人学习、普法备忘，不构成任何技术指导，严禁利用文档内描述的技术概念实施违法网络行为。所有网络测试必须获得合法书面授权。
## 一、刑法四条红线
### 1. 刑法 285 条（非法侵入、非法获取数据、提供黑客工具）
1. 侵入**国家 / 国防 / 尖端科研**系统：只要进去就构成犯罪，3 年以下。
2. 普通网站 / 服务器：**未经授权访问、拿数据、控制服务器**，情节严重，3 年以下；特别严重 3–7 年。
3. 写 / 卖 / 分发**专门用于入侵的工具**（批量撞库、漏洞利用脚本、远控木马），同样入罪。
> 随便扫网上网站、对陌生站点跑 POC、在公网随机探测，哪怕你只是 “练手、好心找漏洞”，**没有书面授权 = 非法侵入**。公开可访问 ≠ 允许你渗透探测。
### 2. 刑法 286 条【破坏计算机信息系统罪】
未经授权删、改、增加数据，DDoS 攻击，篡改网页，造成系统瘫痪、业务中断。后果严重 5 年以下，特别严重 5 年以上。
> 哪怕渗透测试不小心把业务搞崩，**不在授权范围，就是破坏计算机系统**。
### 3. 刑法 253 条之一【侵犯公民个人信息罪】
拿到手机号、身份证、人脸、住址等个人数据，**下载、保存、转发、出售**都算。
- 50 条敏感信息就达到 “情节严重”，3 年以下；大量信息 3–7 年。
> 渗透过程里看到用户数据，**不能下载、截图、外传**，按授权协议处理。
### 4. 帮信罪（刑法 287 条之二）
明知对方用于网络犯罪，还提供服务器、代理、技术支持、工具、流量转发。
> 帮他人搭建VPS、编写脚本，若客观上能预判对方用于网络犯罪，即便口头声称不知情，也可能被认定构成帮信罪。。
## 二、渗透测试必须遵守的硬性规则（行业铁律）
✅ **必须拿到【书面授权文件】**，授权里写清楚：
- 明确的 IP / 域名范围（in-scope）
- 起止时间
- 允许的测试动作（能不能 DDoS、能不能拖库）
- 紧急联系人、应急回滚方案
> 口头授权无效！**超出授权范围的 IP、超出约定时间，一律禁止探测**。关键信息基础设施（政务、电力、运营商、银行）还要额外审批，不能私自探测中国政府网。
❌ 禁止行为：
1. 越界：授权只测 A 网站，你顺带扫 B 网站、内网横向移动到未授权资产
2. 越权：只允许漏洞扫描，你直接拿 shell、拖库、删数据
3. 测试过程留存用户隐私数据、账号密码，测试结束必须销毁
4. 漏洞披露：**未经甲方允许，不能对外公开漏洞**（不能随便发 CSDN、公众号、GitHub），遵循**负责任披露**
## 三、日常工作红线（云原生 / 安全运维 / 红队都适用）
1. **账号权限**：不越权访问生产环境、不私自提权、不私自导出业务数据；工作拿到的账号密码不能私存、外传。
2. **漏洞与工具**
   - 不要开发、传播木马、远控、批量撞库等用于非法入侵的工具；
   - CTF 靶场仅限**本地 / 官方靶场平台**，不能拿公网真实网站练手。
3. **数据红线**
   - 客户、用户数据严禁私自下载、截图、外传；
   - 离职必须删除所有工作敏感数据，不能带走。
4. **日志留痕**：所有操作留审计日志，不要删日志掩盖操作（删日志本身加重情节）。
5. 禁止：DDoS、CC 攻击、刷接口、薅接口数据、爬虫大规模爬取未授权网站。
## 四、行业从业限制
